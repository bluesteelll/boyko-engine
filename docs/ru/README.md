# `docs/ru/` — исключение из правила «всё в репозитории на английском»

CLAUDE.md требует, чтобы каждый артефакт репозитория был на английском: код, комментарии, доки,
сообщения коммитов, промпты агентов. Правило остаётся в силе **везде, кроме этой папки**.

Здесь лежат русские версии документов, которые владелец читает и правит сам. Исключение заведено
владельцем 2026-08-02 и записано в CLAUDE.md, чтобы будущая сессия не сочла эти файлы нарушением и
не «починила» их обратно на английский.

## Что здесь

| файл | оригинал | назначение |
|---|---|---|
| [OPEN-QUESTIONS.md](OPEN-QUESTIONS.md) | [`../OPEN-QUESTIONS.md`](../OPEN-QUESTIONS.md) | журнал открытых вопросов, трудностей и спорных мест |

## Правило синхронизации

**Английская версия — источник истины.** Русская идёт следом, а не наоборот: так внутренние доки,
на которые ссылаются код и другие документы, остаются на одном языке.

Правка любой стороны обязана обновить вторую **в том же коммите**. Разошедшиеся версии хуже
отсутствующей: читатель не знает, какая свежее, и узнаёт об этом только когда действует по
устаревшей.
