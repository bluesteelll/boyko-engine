## Findings

- LATENT DEFECT, read from the code and not reproduced. IslandSleep keys its latch by gather ROW. A despawn between frames swap-removes the archetype row (archetype.rs:1268 "self.entity_ids.swap_remove(removed_unit_index.0);").
