# boyko-W1501 — an ordering references a system set that has no members

## What happened

A schedule build found an ordering edge — `.before(SomeSet)` or `.after(SomeSet)` — naming a set
that no system ever joined:

```text
boyko-W1501: ordering references set 'physics' which has no members (no system joined it via
             in_set); the ordering has no effect
```

Raised at build time from `crates/boyko_ecs/src/ecs/core/schedule/schedule_builder.rs`
(`warn_if_empty`). The build **succeeds**; the schedule runs.

## Why

Set ordering is expanded into per-system edges: `X.before(S)` becomes an edge from `X` to every
member of `S`. A set with no members expands to **no edges at all**, so the ordering the author
wrote is not weakened — it is absent. Nothing about the resulting schedule records that a
constraint was intended.

That is a warning rather than an error because an empty set is legitimate in two cases the builder
cannot distinguish from a typo: a set whose members are added by a plugin that this configuration
did not add, and a set kept as a stable ordering anchor for a feature not yet written. Failing the
build would make either of those a hard stop.

`RatePolicy::Once` per site, because the build walks every ordering edge and a schedule with a
misspelled set name has as many edges as it has systems.

## How to fix

- **The name is a typo, or the set is the wrong one.** Fix the set in the `.before`/`.after` call.
  This is the common case, and it is the one the warning exists for: the ordering silently does
  nothing.
- **The members come from a plugin that is not in this build.** Expected. The ordering will take
  effect when the plugin is added; nothing needs to change.
- **The set is an anchor for future work.** Also expected — and the warning is the reminder that
  it is still empty.

To make a set non-empty, a system joins it with `.in_set(TheSet)`. Nesting one set inside another
does not give the outer set members of its own unless the inner one has some: membership is
transitive through nesting, so an empty inner set contributes nothing to its parent either.
