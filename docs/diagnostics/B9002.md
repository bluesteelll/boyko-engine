# boyko-B9002 — the set hierarchy contains a cycle of sets

## What happened

System sets were nested inside one another in a loop: following the nesting from a set leads back
to that set.

```text
boyko-B9002: set hierarchy contains a cycle of 2 sets: ["Input", "Gameplay"]
```

Raised from `crates/boyko_ecs/src/ecs/core/schedule/schedule_builder.rs`
(`ScheduleBuildError::SetHierarchyCycle`), while the builder flattens the hierarchy into transitive
membership. `build` panics; `try_build` returns it.

## Why

This is about **nesting**, not about ordering — the distinction that its neighbour `boyko-B9001`
covers the other half of. Nesting means "every member of the inner set is also a member of the
outer one", and the builder resolves it transitively so that an ordering edge naming an outer set
reaches every system underneath it.

A cycle makes that resolution non-terminating: `Input` inside `Gameplay` inside `Input` asks for a
membership set that contains itself, expanded forever. The builder detects it and refuses rather
than recursing.

It is reported separately from an ordering cycle because the fix is in a different place. An
ordering cycle is assembled from `.before`/`.after` calls; this one is assembled from `.in_set`
calls on **sets**, which are typically written once, near the plugin that defines them, and read
much less often.

## How to fix

Follow the printed list and remove one nesting edge. The usual causes:

- **Two plugins each nesting the other's set inside their own**, each reasonably, neither seeing
  the pair.
- **A set nested in itself**, directly or through one intermediary — usually a copy-paste of a
  `configure_set` line where one of the two names was not changed.
- **Nesting used where ordering was meant.** "Input runs before Gameplay" is `.before`, not
  `.in_set`. Nesting says the systems *are* in the other set, which is a much stronger claim and
  the one that composes into a cycle.

There is no way to suppress this: a self-containing membership set has no expansion, so there is no
schedule to fall back to.
