# boyko-E3010 - a diagnostic dump could not be written

## What happened

A dump or artifact this run was asked to produce did not reach the filesystem:

```text
boyko-E3010: HZB dump write FAILED (<io error>) -> D:\out\hzb.bin
boyko-E3010: VB-ZONE artifact: could not write D:\out\zone.toml: <io error>
```

Raised from five sites - `host_dump.rs`, `hzb_dump.rs`, `vg_census_dump.rs`, `vb_probe_dump.rs` and
the `VB-ZONE` artifact writer in `runner.rs`. **The run continues and terminates normally**; only
the file is missing.

## Why

Every one of these is armed by an environment variable naming an output path, and every one of them
is read by a gate that reds on the file's absence. So the failure is already caught downstream -
but caught as *"the artifact is not there"*, which is indistinguishable from "the run never got far
enough to write it" and from "the path was wrong". This record is what separates the three.

**Loud, and not a panic**, which is stated at the artifact site itself: the measurement is over by
the time the write runs, and a run that rendered correctly must not be reported as a crash because
a path was unwritable.

`RatePolicy::Every`. Five call sites, one per dump kind, each naming a different path - a run that
armed three dumps and could write none of them has three things to report, not one.

## How to fix

- **Check the directory exists.** None of these writers creates parent directories; a path into a
  directory that is not there fails with `NotFound` and looks like a permissions problem.
- **Check for a stale handle.** On Windows a previous run's viewer holding the file open produces
  `PermissionDenied` on the rewrite, which is the commonest cause when the same path worked once.
- **Check free space.** These artifacts are small except the HZB dump, whose size is the pyramid's
  full mip chain; a nearly full disk fails here first.
- **The env variable is named in the record's path**, so if the path is not what you expected the
  variable was set from a different shell than the one you are reading.
